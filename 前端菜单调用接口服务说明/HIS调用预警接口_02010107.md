# DRG费用预警接口 - 第三方HIS调用说明

## 接口基本信息

| 项目 | 内容 |
|------|------|
| **接口名称** | 新增预警记录（HIS调用接口） |
| **接口Code** | 02010107 |
| **服务类** | `src.DRG.Warning` |
| **功能说明** | HIS系统调用此接口，传入患者就诊费用信息，系统自动匹配预警规则并生成预警记录 |
| **调用场景** | 患者出院结算时、费用累计监控、DRG分组完成后 |

---

## 一、请求格式

### 1.1 请求路径
```
POST /api/drg
Content-Type: application/json
```

### 1.2 请求Body结构
```json
{
  "code": "02010107",
  "params": {
    "hisAdmId": "...",
    "patientName": "...",
    ...
  }
}
```

## 二、请求参数说明

### 2.1 必填参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| **hisAdmId** | String | ✅ | HIS就诊ID（唯一标识一次就诊） | "A20260405001" |
| **patientName** | String | ✅ | 患者姓名 | "张三" |
| **totalFee** | Number | ✅ | 医疗总费用（元，精确到分） | 45000.00 |
| **drgCode** | String | ✅ | DRG编码 | "FB13" |

### 2.2 可选参数

| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| deptCode | String | 科室编码 | "001" |
| deptName | String | 科室名称 | "心内科" |
| doctorCode | String | 医生编码 | "D001" |
| doctorName | String | 医生姓名 | "李医生" |
| drgPayStandard | Number | DRG支付标准（元） | 38000.00 |
| drgName | String | DRG名称 | "心脏介入治疗伴不伴有并发症" |
| medicalRecordDr | String | 病案ID | "MR20260405001" |
| insuranceFee | Number | 医保结算费用（元） | 42000.00 |
| fixmedinsCode | String | 医疗机构代码 | "H001" |
| fixmedinsName | String | 医疗机构名称 | "XX医院" |
| ruleType | String | 指定预警类型（不传则自动匹配所有规则） | "01" |

### 2.3 ruleType 预警类型说明

| 类型代码 | 类型名称 | 说明 |
|----------|----------|------|
| 01 | 费用超支 | 费用超过DRG支付标准的设定比例 |
| 02 | 低倍率 | 费用低于DRG支付标准的设定比例 |
| 03 | 高倍率 | 费用高于DRG支付标准的设定比例 |
| 04 | 编码异常 | 诊断/手术编码存在逻辑异常 |
| 05 | 分解住院 | 疑似分解住院行为 |

## 五、响应字段说明

### 5.1 响应结果（result）

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| warningId | String | 预警记录ID | "123" |
| warningNo | String | 预警流水号（唯一） | "W20260405143000001" |
| ruleCode | String | 触发的规则编码 | "WR001" |
| ruleName | String | 触发的规则名称 | "费用超支预警" |
| warningLevel | Number | 预警级别 | 3 |
| warningMessage | String | 预警消息详情 | "费用超支预警：患者费用总额..." |

### 5.2 预警级别说明

| 级别代码 | 级别名称 | 说明 |
|----------|----------|------|
| 1 | 低 | 提示级别，可关注 |
| 2 | 中 | 警告级别，需关注 |
| 3 | 高 | 严重级别，必须处理 |

### 5.3 费用计算说明

系统自动计算以下费用信息：
- **diffAmount**: 费用差异金额 = totalFee - drgPayStandard
- **diffRate**: 费用差异率 = (totalFee - drgPayStandard) / drgPayStandard × 100%

示例：
- 总费用 45000.00 元，DRG标准 38000.00 元
- 费用差异 = 45000 - 38000 = 7000.00 元
- 差异率 = 7000 / 38000 × 100% = 18.42%

import com.alibaba.fastjson.JSONObject;
import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.charset.StandardCharsets;

public class DRGWarningClient {

    public static JSONObject callAddWarning(JSONObject params) throws Exception {
        URL url = new URL("http://your-server/api/drg");
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        
        conn.setRequestMethod("POST");
        conn.setRequestProperty("Content-Type", "application/json");
        conn.setDoOutput(true);
        
        JSONObject request = new JSONObject();
        request.put("code", "02010107");
        request.put("params", params);
        
        try (OutputStream os = conn.getOutputStream()) {
            os.write(request.toJSONString().getBytes(StandardCharsets.UTF_8));
        }
        
        // 读取响应
        BufferedReader reader = new BufferedReader(
            new InputStreamReader(conn.getInputStream(), StandardCharsets.UTF_8));
        StringBuilder response = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            response.append(line);
        }
        
        return JSONObject.parseObject(response.toString());
    }

    public static void main(String[] args) throws Exception {
        JSONObject params = new JSONObject();
        params.put("hisAdmId", "A20260405001");
        params.put("patientName", "张三");
        params.put("totalFee", 45000.00);
        params.put("drgCode", "FB13");
        params.put("drgPayStandard", 38000.00);

        if ("0".equals(result.getString("errorCode"))) {

## 八、集成建议

### 8.1 推荐调用时机

| 场景 | 调用时机 | 说明 |
|------|----------|------|
| 患者出院结算 | 办理出院时 | 完整费用进行DRG核对 |
| 每日费用累计 | 每日费用更新后 | 费用预警监控 |
| DRG分组完成 | 分组服务返回后 | 触发相关预警 |

### 8.2 预警处理流程

```
HIS调用接口
    ↓
系统匹配预警规则
    ↓
判断是否触发预警
    ↓
┌─────────────────┐
│   无预警触发     │──→ 返回空结果
└─────────────────┘
    ↓
┌─────────────────┐
│   触发预警      │
└─────────────────┘
    ↓
生成预警记录
    ↓
HIS接收预警结果
    ↓
┌─────────────────┐
│ warningLevel=3 │──→ 严重预警 → 医生工作站弹窗提醒
└─────────────────┘
    ↓
┌─────────────────┐
│ warningLevel=1 │──→ 低级预警 → 记录即可
│ warningLevel=2 │──→ 中级预警 → 科室审核
└─────────────────┘
```

### 8.3 注意事项

1. **hisAdmId** 必须唯一标识一次就诊，不可重复使用
2. **totalFee** 和 **drgPayStandard** 建议传入精确到分的金额
3. **ruleType** 为空时会自动匹配所有启用的预警规则
4. 建议HIS端对严重预警（warningLevel=3）进行弹窗提醒
5. 接口支持幂等性：同一就诊ID可多次调用，费用信息会被更新
