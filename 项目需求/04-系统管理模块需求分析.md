# 系统管理模块需求分析

## 1. 模块概述

### 1.1 功能定位
系统管理模块是DRG医保控费预警系统的基础功能模块，用于管理系统用户、角色权限、菜单配置和接口服务，确保系统安全、稳定运行。

### 1.2 业务背景
作为医院信息系统，系统需要严格的权限控制，确保不同角色的用户只能访问其权限范围内的功能。系统管理模块提供用户管理、角色管理、菜单管理、接口配置等基础功能。

### 1.3 目标用户
- 系统管理员
- 医保办管理人员
- 科室管理员

## 2. 功能需求

#### 2.1.1 用户属性
| 属性名称 | 说明 |
|----------|------|
| 用户账号 | 登录账号，唯一 |
| 用户姓名 | 真实姓名 |
| 登录密码 | 登录密码（加密存储） |
| 用户类型 | 01:管理员 02:科室用户 03:医生用户 |

## 4. 接口设计

### 4.1 接口列表

| 接口Code | 接口名称 | 说明 |
|----------|----------|------|
| 02010401 | QuerySystemUsers | 查询系统用户列表 |
| 02010402 | SaveSystemUser | 保存系统用户 |
| 02010403 | QuerySystemMenus | 查询系统菜单 |
| 02010404 | QueryInterfaceServices | 查询接口服务列表 |
| 02010405 | SaveInterfaceService | 保存接口服务 |
| 02010408 | GetUserMenus | 获取用户菜单 |

### 4.2 接口详情

#### 02010401 QuerySystemUsers
- **功能**：查询系统用户列表
- **参数**：userCode, userName, userType, deptCode, isActive, page, limit
- **返回**：用户列表

#### 02010402 SaveSystemUser
- **功能**：保存系统用户（新增/修改）
- **参数**：userId, userCode, userName, password, userType, deptDr, deptName, mobile, email, isActive等
- **返回**：保存结果

#### 02010403 QuerySystemMenus
- **功能**：查询系统菜单列表
- **参数**：menuCode, menuName, parentCode, menuType
- **返回**：菜单列表

#### 02010404 QueryInterfaceServices
- **功能**：查询接口服务列表
- **参数**：interfaceCode, interfaceName, isActive
- **返回**：接口列表

#### 02010405 SaveInterfaceService
- **功能**：保存接口服务配置
- **参数**：interfaceId, interfaceCode, interfaceName, servicePath, serviceClass, methodName等
- **返回**：保存结果

#### 02010408 GetUserMenus
- **功能**：获取用户菜单（用于前端动态渲染菜单）
- **参数**：userId
- **返回**：用户菜单树形结构

## 5. 业务流程

### 5.1 用户创建流程
```
管理员 → 新增用户 → 填写用户信息 → 分配角色 → 保存 → 通知用户
```

### 5.2 权限分配流程
```
管理员 → 选择角色 → 分配菜单权限 → 保存 → 权限生效
```

### 5.3 登录流程
```
用户输入账号密码 → 验证账号密码 → 验证状态 → 获取用户角色 → 获取菜单权限 → 登录成功
```

---

## 6. 性能要求

- 用户查询响应时间 < 1秒
- 菜单加载响应时间 < 1秒
- 登录验证响应时间 < 500ms
- 支持1000+并发用户

---

## 7. 安全要求

- 密码加密存储（MD5/SHA256）
- 密码强度要求（至少8位，含数字和字母）
- 登录失败锁定机制
- 操作日志完整记录
- SQL注入防护
- XSS攻击防护
- 数据传输加密（HTTPS）
