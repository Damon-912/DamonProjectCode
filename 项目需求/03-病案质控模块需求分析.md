# 病案质控模块需求分析

## 1. 模块概述

### 1.1 功能定位
病案质控模块是DRG医保控费预警系统的核心功能模块，用于对病案首页信息进行自动化质控检查，发现并纠正病案填写问题，提高病案数据质量，确保DRG分组的准确性。

### 1.2 业务背景
病案首页是DRG分组的基础依据，病案数据质量直接影响DRG分组结果，进而影响医保支付。病案质控模块通过规则引擎自动检查病案填写规范性，及时发现诊断漏填、手术漏填、费用异常等问题，减少因病案质量问题导致的医保拒付。

### 1.3 目标用户
- 质控人员
- 医保办管理人员
- 科室质控员
- 病案室编码员
- 医生

## 2. 功能需求

### 2.1 质控规则管理

#### 2.1.1 内置质控规则
系统预置以下质控规则：

| 规则类型 | 规则名称 | 说明 |
|----------|----------|------|
| 必填项检查 | 主要诊断为空 | 主要诊断不能为空 |
| 必填项检查 | 主要手术为空 | 主要手术不能为空 |
| 必填项检查 | 入院方式为空 | 入院方式不能为空 |
| 必填项检查 | 出院方式为空 | 出院方式不能为空 |
| 逻辑检查 | 出院日期早于入院日期 | 数据逻辑错误 |
| 逻辑检查 | 住院天数异常 | 住院天数<0或超过365天 |
| 一致性检查 | 有诊断无手术 | 有主要诊断但无手术操作 |
| 一致性检查 | 年龄与诊断不匹配 | 儿童诊断出现在成人病历 |
| 费用检查 | 费用超过均值2倍 | 费用异常偏高 |
| 费用检查 | 费用低于均值50% | 费用异常偏低 |
| 编码检查 | 主诊断不在MDC范围 | 主诊断与MDC不匹配 |
| 编码检查 | 手术编码无效 | 手术编码不存在 |
| DRG相关 | 未入组病例 | 病例未成功DRG分组 |

#### 2.1.2 质控规则属性
- 规则编码
- 规则名称
- 规则描述
- 问题类型（01:必填项 02:逻辑错误 03:一致性 04:费用异常 05:编码错误）
- 问题级别（1:提示 2:警告 3:严重）
- 检查字段
- 检查条件
- 提示信息
- 是否启用
- 排序号

#### 2.1.3 质控规则CRUD
- 查看内置规则
- 启用/停用规则
- 自定义规则（可选）

### 2.2 质控检查

#### 2.2.1 触发方式
- **实时检查**：病案保存时自动触发
- **定时检查**：每日定时全量检查
- **手动检查**：用户选择病案手动触发

#### 2.2.2 检查流程
```
选择病案 → 执行质控规则 → 生成问题列表 → 问题分类展示 → 问题处理 → 归档
```

#### 2.2.3 质控结果展示
- 病案基本信息
- 问题列表（按严重程度排序）
- 问题详情（问题描述、涉及字段、建议修改值）
- 历史质控记录

### 2.3 质控问题管理

#### 2.3.1 问题记录属性
- 病案ID
- 问题类型
- 问题级别
- 问题描述
- 问题字段
- 当前值
- 建议值
- 检查时间
- 处理状态（待处理/已处理/已忽略）

- 处理时间
- 处理意见

#### 2.3.2 问题处理
- 查看问题详情
- 填写处理意见
- 标记为已处理
- 标记为已忽略
- 批量处理
- 问题追溯

#### 2.3.3 问题查询
- 按时间范围查询
- 按科室查询
- 按医生查询
- 按问题类型查询
- 按问题级别查询
- 按处理状态查询

### 2.4 质控统计

#### 2.4.1 统计维度
- 质控数量统计（按时间、科室、类型）
- 问题分布统计
- 问题处理率统计
- 科室问题排行

#### 2.4.2 报表功能

- 问题明细报表
- 科室质控评分报表
- 问题趋势分析图

### 2.5 病案编码辅助

#### 2.5.1 编码推荐
- 根据诊断推荐手术编码
- 根据手术推荐诊断编码
- 相似病案编码参考

#### 2.5.2 编码校验
- 医保目录校验
- 编码格式校验
- 编码一致性校验

## 4. 接口设计

### 4.1 接口列表

| 接口Code | 接口名称 | 说明 |
|----------|----------|------|
| 02010301 | PerformQCCheck | 执行质控检查 |
| 02010302 | QueryQCIssues | 查询质控问题 |

### 4.2 接口详情

#### 02010301 PerformQCCheck
- **功能**：执行病案质控检查
- **参数**：medicalRecordId
- **返回**：质控结果列表

#### 02010302 QueryQCIssues
- **功能**：查询质控问题列表
- **参数**：startDate, endDate, deptCode, doctorCode, issueType, issueLevel, processStatus, page, limit
- **返回**：质控问题列表

## 5. 业务流程

### 5.1 实时质控流程
```
医生填写病案 → 病案保存 → 触发质控检查 → 生成问题列表 → 提示医生 → 医生修改 → 再次检查 → 通过
```

### 5.2 定时质控流程
```
系统定时任务 → 选取未质控病案 → 批量执行质控 → 生成问题 → 通知科室 → 问题处理 → 归档
```

### 5.3 质控审核流程
```
质控问题生成 → 科室确认 → 质控审核 → 确认问题 → 病案修改 → 再次质控 → 通过
```

## 6. 性能要求

- 单个病案质控响应时间 < 2秒
- 批量质控（100份）响应时间 < 30秒
- 问题查询响应时间 < 2秒
- 支持1000+并发用户
