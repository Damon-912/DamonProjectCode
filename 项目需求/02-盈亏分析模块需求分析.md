# 盈亏分析模块需求分析

## 1. 模块概述

### 1.1 功能定位
盈亏分析模块是DRG医保控费预警系统的重要功能模块，用于分析各科室、医生、病种的DRG盈亏情况，为医院成本控制和绩效管理提供数据支撑。

### 1.2 业务背景
DRG付费模式下，医院的收入与病例分组（DRG）密切相关。当实际医疗费用低于DRG支付标准时为盈余，反之为亏损。准确掌握各科室、医生、病种的盈亏情况，对于优化诊疗方案、控制医疗成本具有重要意义。

### 1.3 目标用户
- 医院管理者
- 医保办管理人员
- 科室主任
- 主诊医生
- 财务人员
- 质控人员

## 2. 功能需求

### 2.1 科室盈亏分析

#### 2.1.1 分析维度
- 按月度/季度/年度统计
- 按科室/病区统计
- 按DRG病组分类统计

#### 2.1.2 分析指标
| 指标名称 | 说明 |
|----------|------|
| 出院人次 | 统计期间内该科室出院患者数量 |
| 入组病例数 | 成功进入DRG分组的病例数 |
| 入组率 | 入组病例数/出院人次 × 100% |
| 总费用 | 科室所有出院患者医疗费用总和 |
| 医保支付标准 | DRG分组对应的支付标准总和 |
| 盈亏金额 | 医保支付标准 - 总费用 |
| 盈亏率 | 盈亏金额/医保支付标准 × 100% |
| CMI值 | 病例组合指数，反映科室收治病例难度 |
| 次均费用 | 总费用/出院人次 |
| 时间消耗指数 | 实际住院天数/该DRG平均住院天数 |
| 费用消耗指数 | 实际费用/该DRG平均费用 |

#### 2.1.3 展示形式
- 数据表格（支持排序、筛选、分页）
- 趋势折线图（显示月度变化）
- 构成饼图（显示盈亏构成）
- 仪表盘（关键指标一目了然）

### 2.2 医生盈亏分析

#### 2.2.1 分析维度
- 按医生统计
- 按诊疗组统计
- 按时间维度（月/季/年）

#### 2.2.2 分析指标
| 指标名称 | 说明 |
|----------|------|
| 主管病例数 | 该医生主管的出院病例数 |
| 入组病例数 | 成功入组病例数 |
| 入组率 | 入组病例数/主管病例数 × 100% |
| 总费用 | 主管病例医疗费用总和 |
| 医保支付标准 | DRG支付标准总和 |
| 盈亏金额 | 医保支付标准 - 总费用 |
| 盈亏率 | 盈亏金额/医保支付标准 × 100% |
| CMI值 | 该医生病例组合指数 |
| 低风险死亡率 | 低风险组病例死亡占比 |

#### 2.2.3 展示形式
- 医生排行榜（按盈亏金额排序）
- 医生详情页面
- 趋势图

### 2.3 病种盈亏分析

#### 2.3.1 分析维度
- 按MDC大类分析
- 按ADRG分析
- 按DRG细分组分析

#### 2.3.2 分析指标
| 指标名称 | 说明 |
|----------|------|
| 病例数 | 该病种出院病例数 |
| 占比 | 病例数/总病例数 × 100% |
| 平均费用 | 该病种平均医疗费用 |
| 支付标准 | DRG支付标准 |
| 平均盈亏 | 每病例平均盈亏金额 |
| 病种盈亏 | 该病种总盈亏金额 |
| 盈亏占比 | 病种盈亏/总盈亏 × 100% |

#### 2.3.3 展示形式
- 病种排行榜（按盈亏/病例数排序）
- 病种详情页面
- 同病种费用分布图

### 2.4 汇总分析

#### 2.4.1 医院整体盈亏
- 全院月度/年度盈亏汇总
- 各科室盈亏占比
- 盈亏趋势分析

#### 2.4.2 对标分析
- 与历史同期对比
- 与预算目标对比
- 与同级医院对比（如有数据）

### 2.5 数据导出

- 支持导出Excel格式
- 支持导出PDF报表
- 支持自定义时间范围
- 支持按科室/医生筛选导出

## 4. 接口设计

### 4.1 接口列表

| 接口Code | 接口名称 | 说明 |
|----------|----------|------|
| 02010201 | QueryDeptProfit | 查询科室盈亏 |
| 02010202 | QueryDoctorProfit | 查询医生盈亏 |
| 02010203 | QueryDiseaseProfit | 查询病种盈亏 |

### 4.2 接口详情

#### 02010201 QueryDeptProfit
- **功能**：查询科室盈亏数据
- **参数**：year, month, deptCode, startDate, endDate, page, limit
- **返回**：科室盈亏列表

#### 02010202 QueryDoctorProfit
- **功能**：查询医生盈亏数据
- **参数**：year, month, doctorCode, deptCode, startDate, endDate, page, limit
- **返回**：医生盈亏列表

#### 02010203 QueryDiseaseProfit
- **功能**：查询病种盈亏数据
- **参数**：year, month, mdcCode, adrgCode, drgCode, startDate, endDate, page, limit
- **返回**：病种盈亏列表

## 5. 业务流程

### 5.1 数据分析流程
```
病案数据入库 → DRG分组计算 → 费用对比分析 → 生成盈亏数据 → 数据展示/导出
```

### 5.2 定期汇总流程
```
每月1日 → 汇总上月数据 → 计算科室/医生/病种盈亏 → 生成汇总报表 → 数据分析
```
