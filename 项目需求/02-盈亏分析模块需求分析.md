# 盈亏分析模块需求分析

## 1. 模块概述

### 1.1 功能定位
盈亏分析模块用于分析各科室、医生、病种的DRG/DIP盈亏情况，帮助医院管理者了解医疗收入与成本的关系，优化诊疗结构，实现医保基金的有效利用。

### 1.2 业务背景
DRG/DIP付费模式下，医院的收入取决于病种的分组结果。同一病种的医疗费用与支付标准之间的差异直接影响医院的盈亏。本模块通过多维度的盈亏分析，帮助医院发现问题病种、问题科室、问题医生，并进行针对性改进。

### 1.3 目标用户
- 医院管理层
- 医保办管理人员
- 科室主任
- 主诊医生
- 质控人员

## 4. 核心指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| 盈亏金额 | 支付标准 - 医疗费用 | DrgPayment - TotalCost |
| 盈亏率 | 盈亏金额/支付标准*100% | BalanceAmount / DrgPayment * 100% |
| 病例构成 | 各盈亏类型病例占比 | Count / Total * 100% |
| 平均住院费用 | 费用总额/病例数 | TotalCost / CaseCount |
| 平均盈亏 | 盈亏总额/病例数 | TotalBalance / CaseCount |
