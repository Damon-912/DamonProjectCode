# 接口映射管理模块需求分析

## 1. 模块概述

### 1.1 功能定位
接口映射管理模块是DRG医保控费预警系统的核心配置模块，负责管理前端菜单与后端IRIS服务接口之间的映射关系。所有前端菜单调用后端接口服务都需要通过维护 `CB_MapInterface` 表的接口服务信息后才能正常调用。

### 1.2 业务背景
- 系统中存在大量后端服务接口（DRG分组、费用预警、盈亏分析、病案质控、系统管理等）
- 前端菜单与后端接口需要通过映射表进行关联
- 接口调用需要进行权限验证（Session/Token）
- 需要可视化管理界面来配置和维护接口映射

### 1.3 目标用户
- 系统管理员：负责接口映射配置和维护
- 开发人员：查看接口定义和调用方式
- 测试人员：测试接口功能

---

## 2. 功能需求

### 2.1 接口映射维护

#### 2.1.1 接口列表查询
- 支持分页查询接口映射列表
- 支持按接口Code、描述、类名、方法名模糊搜索
- 支持按服务类型、产品分类、产品模块筛选
- 显示字段：Code、Descripts、ClassName、MethodName、ServiceType、ProductCatDr、ProductModuleDr、StartDate、StopDate

#### 2.1.2 接口新增
- 必填字段：Code、Descripts、ClassName、MethodName、ServiceType
- 选填字段：StartDate、StopDate、ProductCatDr、ProductModuleDr、SeqNo、ServiceIP、SessionFlag、TokenFlag、TokenOverTime、RWServiceTypeDr
- Code唯一性校验
- ClassName+MethodName组合唯一性校验

#### 2.1.3 接口编辑
- 可修改所有字段
- 维护失效日期后，该接口不再可用

#### 2.1.4 接口删除
- 逻辑删除（设置失效日期）
- 支持批量操作

### 2.2 接口测试

#### 2.2.1 接口调用测试
- 选择已配置的接口
- 填写请求参数（JSON格式）
- 执行调用并返回结果
- 显示请求耗时、响应状态

#### 2.2.2 常用接口模板
- 预置常用接口的请求参数模板
- 支持保存自定义测试模板

### 2.3 接口授权

#### 2.3.1 菜单关联
- 将接口映射到系统菜单
- 一个接口可关联多个菜单
- 一个菜单可关联多个接口

#### 2.3.2 角色授权
- 将接口映射分配给角色
- 角色通过菜单间接获得接口权限

### 2.4 接口日志

#### 2.4.1 调用日志记录
- 记录每次接口调用
- 字段：调用时间、接口Code、用户ID、会话ID、请求参数、响应结果、执行时长

#### 2.4.2 日志查询
- 按时间范围、接口Code、用户查询
- 支持导出Excel

## 3. 数据模型

### 3.1 核心表结构

#### 3.1.1 接口映射表 (CB_MapInterface)
**类名**: `User.CBMapInterface`  
**表名**: `CB_MapInterface`

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Code | VARCHAR(8) | 是 | 接口代码，唯一索引 |
| Descripts | VARCHAR(50) | 是 | 接口描述 |
| ClassName | VARCHAR(100) | 是 | IRIS服务类名 |
| MethodName | VARCHAR(50) | 是 | 方法名，与ClassName组合唯一 |
| StartDate | DATE | 否 | 生效日期 |
| StopDate | DATE | 否 | 失效日期 |
| ServiceType | VARCHAR(1) | 是 | 服务类型：S=查询、A=新增、U=修改、D=删除 |
| ProductCatDr | VARCHAR(50) | 否 | 产品分类（外键CBProductCat） |
| ProductModuleDr | VARCHAR(50) | 否 | 产品模块（外键CBProductModule） |
| SeqNo | VARCHAR(4) | 否 | 序号（排序用） |
| ServiceIP | VARCHAR(30) | 否 | 服务器地址 |
| SessionFlag | VARCHAR(1) | 是 | 是否验证Session：Y=是、N=否 |
| TokenFlag | VARCHAR(1) | 是 | 是否验证Token：Y=是、N=否 |
| TokenOverTime | VARCHAR(5) | 否 | Token超时时间（分钟） |
| RWServiceTypeDr | VARCHAR(50) | 否 | 读写类型（外键CBSysServiceType） |

#### 3.1.2 接口日志表 (CB_MapInterfaceLog)
**类名**: `User.CBMapInterfaceLog`  
**表名**: `CB_MapInterfaceLog`

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ID | BIGINT | 是 | 主键ID |
| InterfaceCode | VARCHAR(8) | 是 | 接口代码 |
| InterfaceName | VARCHAR(100) | 否 | 接口描述 |
| UserID | VARCHAR(50) | 否 | 调用用户ID |
| SessionID | VARCHAR(100) | 否 | 会话ID |
| RequestParams | TEXT | 否 | 请求参数（JSON） |
| ResponseResult | TEXT | 否 | 响应结果（JSON） |
| ExecuteTime | INT | 否 | 执行时长（毫秒） |
| Status | VARCHAR(1) | 是 | 状态：S=成功、F=失败 |
| ErrorMessage | VARCHAR(500) | 否 | 错误信息 |
| CreateDate | DATE | 是 | 创建日期 |
| CreateTime | TIME | 是 | 创建时间 |

## 4. 接口设计

### 4.1 接口列表

| 接口Code | 接口名称 | 服务类 | 方法名 | 说明 |
|----------|----------|--------|--------|------|
| 02010404 | 查询接口服务 | User.DRG.System | QueryInterfaceServices | 查询接口映射列表 |
| 02010405 | 保存接口服务 | User.DRG.System | SaveInterfaceService | 新增/修改接口映射 |
| 02010412 | 删除接口服务 | User.DRG.System | DeleteInterfaceService | 删除接口映射 |
| 02010413 | 测试接口调用 | User.DRG.System | TestInterfaceCall | 测试接口调用 |
| 02010414 | 查询接口日志 | User.DRG.System | QueryInterfaceLogs | 查询接口调用日志 |

### 4.2 接口详情

#### 02010404 查询接口服务
- **功能**：查询接口映射列表
- **参数**：
  - page: 页码
  - limit: 每页条数
  - code: 接口Code（模糊）
  - descriptions: 描述（模糊）
  - className: 类名（模糊）
  - methodName: 方法名（模糊）
  - serviceType: 服务类型
  - productCatDr: 产品分类
  - productModuleDr: 产品模块
- **返回**：分页列表，包含所有字段

#### 02010405 保存接口服务
- **功能**：新增或修改接口映射
- **参数**：
  - id: ID（空为新增，有值为修改）
  - code: 接口Code
  - descriptions: 描述
  - className: 类名
  - methodName: 方法名
  - startDate: 生效日期
  - stopDate: 失效日期
  - serviceType: 服务类型
  - productCatDr: 产品分类
  - productModuleDr: 产品模块
  - seqNo: 序号
  - serviceIP: 服务器地址
  - sessionFlag: 是否验证Session
  - tokenFlag: 是否验证Token
  - tokenOverTime: Token超时时间
  - rwServiceTypeDr: 读写类型
- **返回**：保存结果

#### 02010412 删除接口服务
- **功能**：删除接口映射（逻辑删除）
- **参数**：id: 接口映射ID
- **返回**：删除结果

#### 02010413 测试接口调用
- **功能**：测试接口调用
- **参数**：
  - interfaceCode: 接口Code
  - params: 请求参数（JSON）
- **返回**：接口响应结果、执行时长

#### 02010414 查询接口日志
- **功能**：查询接口调用日志
- **参数**：
  - page: 页码
  - limit: 每页条数
  - interfaceCode: 接口Code
  - userID: 用户ID
  - startDate: 开始日期
  - endDate: 结束日期
  - status: 状态
- **返回**：分页日志列表

## 5. 业务流程

### 5.1 接口映射维护流程
```
管理员登录 → 进入接口管理 → 查询接口列表 → 新增/编辑/删除接口 → 保存 → 同步到CB_MapInterface表
```

### 5.2 接口测试流程
```
选择接口 → 填写参数 → 执行调用 → 查看响应 → 记录日志
```

### 5.3 接口调用流程
```
前端请求 → 验证Session/Token → 查询CB_MapInterface获取类名方法 → 调用对应服务 → 记录日志 → 返回结果
```

---

## 6. 性能要求

- 接口列表查询响应时间 < 500ms
- 接口调用测试响应时间 < 3s
- 支持1000+接口映射配置
- 日志存储保留90天

---

## 7. 安全要求

- 接口配置需有相应权限才能操作
- 敏感操作需记录操作日志
- 接口调用需验证Session或Token

---

## 8. 验收标准

1. ✅ 可查询、新增、修改、删除接口映射记录
2. ✅ Code和ClassName+MethodName组合唯一性校验生效
3. ✅ 可对已配置接口进行测试调用
4. ✅ 接口调用日志自动记录
5. ✅ 失效日期后的接口不可用
6. ✅ 界面符合系统统一风格
