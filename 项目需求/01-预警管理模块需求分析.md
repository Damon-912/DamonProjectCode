# 预警管理模块需求分析

## 1. 模块概述

### 1.1 功能定位
预警管理模块是DRG医保控费预警系统的核心功能模块，用于定义和管理各类医保控费预警规则，对患者诊疗过程进行实时监控，及时发现异常医疗行为并进行预警提示。

### 1.2 业务背景
随着医保支付方式改革（DRG/DIP），医疗机构需要严格控制医疗成本，避免因费用超支、低倍率、高倍率等问题导致医保拒付或扣款。本模块通过建立预警机制，帮助医院管理者和临床医生及时发现问题，降低医保拒付风险。

### 1.3 目标用户
- 医保办管理人员
- 科室主任/护士长
- 主诊医生
- 质控人员
- 财务人员

## 2. 功能需求

### 2.1 预警规则管理

#### 2.1.1 预警规则定义
系统支持定义以下类型的预警规则：

| 规则类型 | 代码 | 说明 |
|---------|------|------|
| 费用超支 | 01 | 医疗费用超过设定阈值 |
| 低倍率 | 02 | 费用低于DRG支付标准的设定比例 |
| 高倍率 | 03 | 费用高于DRG支付标准的设定比例 |
| 编码异常 | 04 | 诊断/手术编码存在异常 |
| 分解住院 | 05 | 疑似分解住院行为 |

#### 2.1.2 预警规则属性
- **规则编码**：唯一标识，支持英文字母和数字
- **规则名称**：规则的中文名称
- **规则描述**：规则的详细说明
- **规则类型**：见上表
- **阈值类型**：固定值/百分比/动态计算
- **阈值**：具体数值
- **关联MDC/ADRG/DRG**：可选，限定规则适用范围
- **预警级别**：
  - 1级（提示）：绿色提示
  - 2级（警告）：黄色警告
  - 3级（严重）：红色严重警告
- **是否启用**：启用/停用
- **排序号**：显示顺序
- **创建人/创建时间**
- **修改人/修改时间**

#### 2.1.3 预警规则CRUD
- 新增预警规则
- 修改预警规则
- 删除预警规则（逻辑删除）
- 查询预警规则列表（支持按规则编码、名称、类型、状态筛选）
- 启用/停用预警规则

### 2.2 预警记录管理

#### 2.2.1 预警触发机制
- 实时预警：诊疗过程中即时触发
- 定时预警：每日定时扫描病案数据
- 手动预警：用户手动触发检查

#### 2.2.2 预警记录属性
- 预警记录ID
- 关联病案ID
- 触发规则ID
- 预警类型
- 预警级别
- 预警内容
- 触发时间
- 处理状态（待处理/已处理/已忽略）
- 处理人
- 处理时间
- 处理意见

#### 2.2.3 预警记录查询
- 按时间范围查询
- 按科室查询
- 按医生查询
- 按预警类型查询
- 按预警级别查询
- 按处理状态查询
- 分页展示

### 2.3 预警处理

#### 2.3.1 预警处理流程
1. 预警触发 → 生成预警记录
2. 预警通知 → 消息推送（可选）
3. 预警处理 → 医生/科室处理
4. 质控审核 → 质控人员复核
5. 归档 → 完成处理

#### 2.3.2 预警处理功能
- 查看预警详情
- 填写处理意见
- 标记为已处理
- 标记为已忽略
- 批量处理预警
- 预警统计报表

### 2.4 预警统计

#### 2.4.1 统计维度
- 预警数量统计（按时间、科室、类型、级别）
- 预警处理率统计
- 预警趋势分析
- 科室预警排行
- 医生预警排行
- 高频预警规则分析

#### 2.4.2 报表功能
- 预警汇总报表
- 预警明细报表
- 预警趋势图
- 导出Excel/PDF

## 4. 接口设计

### 4.1 接口列表

| 接口Code | 接口名称 | 说明 |
|----------|----------|------|
| 02010101 | QueryWarningRules | 查询预警规则列表 |
| 02010102 | SaveWarningRule | 保存预警规则 |
| 02010103 | QueryWarningRecords | 查询预警记录 |
| 02010104 | ProcessWarning | 处理预警 |

### 4.2 接口详情

#### 02010101 QueryWarningRules
- **功能**：查询预警规则列表
- **参数**：ruleCode, ruleName, ruleType, isActive, page, limit
- **返回**：规则列表数据

#### 02010102 SaveWarningRule
- **功能**：保存预警规则（新增/修改）
- **参数**：ruleId, ruleCode, ruleName, ruleDesc, ruleType, thresholdType, thresholdValue等
- **返回**：保存结果

#### 02010103 QueryWarningRecords
- **功能**：查询预警记录
- **参数**：startDate, endDate, deptCode, doctorCode, warningType, warningLevel, processStatus, page, limit
- **返回**：预警记录列表

#### 02010104 ProcessWarning
- **功能**：处理预警记录
- **参数**：recordId, processStatus, processRemark
- **返回**：处理结果

## 5. 业务流程

### 5.1 预警规则定义流程
```
管理员 → 新增规则 → 填写规则信息 → 关联病种范围 → 设置阈值 → 保存规则 → 启用规则
```

### 5.2 预警触发处理流程
```
病案数据 → 规则引擎匹配 → 触发预警 → 生成预警记录 → 消息通知 → 医生处理 → 质控审核 → 完成
```

## 6. 性能要求

- 预警规则查询响应时间 < 1秒
- 预警记录查询响应时间 < 2秒
- 支持1000+并发用户
- 预警处理无延迟（实时）
