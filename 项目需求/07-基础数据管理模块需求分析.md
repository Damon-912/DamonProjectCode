# 基础数据管理模块需求分析

## 1. 模块概述

### 1.1 功能定位
基础数据管理模块提供DRG系统的核心基础数据维护功能，包括DRG基础数据、ICD编码管理、ADRG分组规则维护、DRG核心算法配置维护，以及接口服务配置和日志管理。

### 1.2 业务背景
DRG分组器的运行依赖准确的基础数据配置，包括：
- **DRG基础数据**：MDC/ADRG/DRG编码体系及其版本管理
- **ICD编码**：ICD-9-CM-3手术编码和ICD-10诊断编码的维护及映射
- **ADRG分组规则**：核心疾病诊断相关分组的入组条件规则
- **DRG核心算法**：各DRG分组的支付参数（点数、系数、支付标准）
- **接口服务配置**：系统接口服务的统一注册和管理

### 1.3 目标用户
- 系统管理员
- 医保办管理人员
- DRG编码管理人员

## 2. 功能需求

### 2.1 DRG基础数据维护 ⏳ 待开发

#### 2.1.1 功能说明
维护DRG编码体系的基础数据，包括MDC、ADRG、DRG编码及其版本信息。

#### 2.1.2 数据结构
- 主表：HB_DRGBasicData
- 明细表：HB_DRGBasicDataSub

#### 2.1.3 操作功能
- 查询：按版本号/编码/描述筛选（分页）
- 新增：录入基础数据主表及明细
- 编辑：修改已有基础数据
- 删除：删除基础数据（主表+明细）

**对应接口**: 02010010, 02010011, 02010012, 02010013, 02010014, 02010015

**对应页面**: `/standard/basic-data`

---

### 2.2 ICD编码映射 ⏳ 待开发

#### 2.2.1 功能说明
管理地方ICD编码与国家医保ICD编码的映射关系，支持不同版本和地区。

#### 2.2.2 数据结构
- 映射表：HB_DRGICDVersionMapping
- 医保ICD来源：HB_DRGBasicData + HB_DRGBasicDataSub

#### 2.2.3 操作功能
- 查询：按版本号/省市/编码模糊匹配（分页）
- 新增映射：选择地方ICD + 医保ICD建立映射
- 编辑映射：修改映射关系
- 删除映射：单条/批量删除
- 从ICD库选择：弹窗查询医保ICD编码

**对应接口**: 02010022, 02010023（保存/删除/查询映射）

**对应页面**: `/standard/icd-mapping`

---

### 2.3 ICD编码查询 ⏳ 待开发

#### 2.3.1 功能说明
查询各地方版本的ICD编码库，支持ICD-9-CM-3和ICD-10两个版本。

#### 2.3.2 数据结构
- 编码库：BS_DRGICDInfo

#### 2.3.3 操作功能
- 查询：按版本/省市/编码模糊匹配/状态筛选（分页）

**对应接口**: 02010037

**对应页面**: `/standard/icd9cm3`、`/standard/icd10`

### 2.4 ADRG分组规则维护 ⏳ 待开发

#### 2.4.1 功能说明
管理核心疾病诊断相关分组（ADRG）的入组规则，定义各ADRG的诊断和手术入组条件。

#### 2.4.2 数据结构
- 规则表：CB_DRGCoreGroupsList

#### 2.4.3 操作功能
- 查询：按ADRG名称模糊匹配/状态筛选（分页）
- 新增规则：录入ADRG代码/名称、三级诊断编码、三级手术编码、联合标志、省市、日期
- 编辑规则：修改已有规则
- 删除规则：单条删除
- 展开行：查看完整的诊断和手术编码详情

**对应接口**: 02010016, 02010017, 02010018

**对应页面**: `/standard/adrg-rule`

---

### 2.5 DRG核心算法配置维护 ⏳ 待开发

#### 2.5.1 功能说明
管理DRG核心算法参数，包括各DRG分组的基准点数、预估点值、病组差异系数、支付标准等。

#### 2.5.2 数据结构
- 配置表：HB_DRGCoreAlgorithmData

#### 2.5.3 核心字段
| 字段 | 说明 |
|------|------|
| DRG | DRG编码 |
| DRGDesc | DRG描述 |
| Points | 基准点数 |
| PipValue | 预估点值 |
| DGDOV | 病组差异系数 |
| PayStandard | 支付标准 |
| InsuType | 险种类型 |
| MdtrtArea | 就医地区划代码 |
| MedinsLv | 医疗机构等级 |
| FixmedinsCode/Name | 医疗机构代码/名称 |
| ProvinceDr/CityDr | 省/市 |

#### 2.5.4 操作功能
- 查询：按DRG编码/医疗机构名称/省市/状态（分页）
- 新增配置：录入完整的算法参数
- 编辑配置：修改已有配置
- 删除配置：单条删除

**对应接口**: 02010032, 02010033, 02010034

**对应页面**: `/standard/drg-algorithm`
