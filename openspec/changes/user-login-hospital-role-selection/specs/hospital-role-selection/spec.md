## ADDED Requirements

### Requirement: 获取登录权限列表
系统SHALL在用户验证通过后，调用后端接口 code 01010004 获取该用户可选的登录权限列表（医院+角色组合）。

#### Scenario: 获取权限列表成功
- **WHEN** 用户验证通过后进入选择页面
- **THEN** 系统调用 GetLogonGroupByUserId 接口，传入 userID
- **AND** 接口返回该用户关联的所有医院+角色组合列表
- **AND** 页面展示这些权限组合

#### Scenario: 权限列表为空
- **WHEN** 调用 GetLogonGroupByUserId 接口返回空列表
- **THEN** 页面显示提示"您没有可用的登录权限，请联系管理员分配"
- **AND** 提供"返回登录页"按钮

### Requirement: 医院角色选择页面展示
系统SHALL以卡片列表形式展示用户的医院+角色组合，每个卡片显示医院名称、医院编码、角色名称、是否默认等信息。

#### Scenario: 展示权限卡片
- **WHEN** 页面加载完成并获取到权限列表
- **THEN** 以卡片网格布局展示每个权限组合
- **AND** 每个卡片显示：医院名称（大字）、角色名称（标签）、医院编码（小字）
- **AND** 默认权限的卡片显示"默认"标识

#### Scenario: 大量权限分页展示
- **WHEN** 用户有超过12个权限组合
- **THEN** 卡片列表分页展示，每页12个
- **AND** 提供分页切换控件

### Requirement: 搜索筛选功能
系统SHALL提供按医院名称和角色名称搜索筛选功能，帮助用户快速找到目标权限。

#### Scenario: 按医院名称搜索
- **WHEN** 用户在搜索框输入医院名称关键字
- **THEN** 实时过滤显示匹配的医院权限卡片
- **AND** 支持模糊匹配

#### Scenario: 按角色名称搜索
- **WHEN** 用户在搜索框输入角色名称关键字
- **THEN** 实时过滤显示匹配的角色权限卡片
- **AND** 支持模糊匹配

#### Scenario: 清空搜索
- **WHEN** 用户点击搜索框的清空按钮
- **THEN** 显示所有权限卡片
- **AND** 搜索框清空

### Requirement: 选择权限并登录
系统SHALL允许用户点击权限卡片选择该组合，并进入登录流程。

#### Scenario: 点击权限卡片
- **WHEN** 用户点击某个权限卡片
- **THEN** 该卡片显示选中状态（边框高亮）
- **AND** "进入系统"按钮变为可用状态

#### Scenario: 点击"进入系统"按钮
- **WHEN** 用户选中权限后点击"进入系统"按钮
- **THEN** 系统调用 Logon 接口完成登录
- **AND** 显示加载状态
- **AND** 登录成功后跳转主页面

#### Scenario: 未选择权限点击登录
- **WHEN** 用户未选择任何权限就点击"进入系统"
- **THEN** 提示"请选择一个登录权限"
- **AND" 不调用登录接口
