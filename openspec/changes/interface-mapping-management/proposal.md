# 接口映射管理 - 需求提案

## 1. 变更概述

### 变更名称
`interface-mapping-management`

### 变更描述
为 `CB_MapInterface` 接口映射表创建前端维护菜单及接口调用功能，实现前端菜单与后端IRIS服务接口的注册、配置和调用能力。

### 业务背景
- 前端菜单调用后端接口服务都需要通过维护 `CB_MapInterface` 表的接口服务信息后才能调用
- 需要提供可视化的界面来管理接口映射配置
- 支持接口的增删改查、服务类型配置、权限验证设置

## 2. 现状分析

### 当前问题
1. 接口映射信息仅存在于 `CB_MapInterface.xlsx` 文件中
2. 缺乏前端维护界面，需手动维护Excel后导入
3. 接口调用链路不透明，难以管理

### 目标系统
- IRIS数据库 `User.CBMapInterface` 表
- 后端服务类 `src.DRG.Interface`
- 前端React/Vue页面

## 3. 需求范围

### 功能模块
1. **接口映射维护** - CRUD接口服务映射配置
2. **接口测试** - 直接调用已配置接口进行测试
3. **接口授权** - 关联菜单、角色、权限
4. **接口日志** - 记录接口调用情况
