# ICD编码映射与ICD编码查询

## 概述

在"基础数据管理"模块下新增两个功能页面：**ICD编码映射** 和 **ICD编码查询**，用于管理地方ICD编码与医保ICD编码的映射关系，以及查询各地方版本的ICD编码库。

## 背景

- DRG分组依赖ICD编码，不同地区可能使用不同的ICD编码版本
- 需要建立地方ICD编码与国家医保ICD编码的映射关系
- 需要提供ICD编码库的查询能力，支持ICD-9-CM-3和ICD-10两个版本

## 涉及的数据库表

| 表名 | 说明 |
|------|------|
| `HB_DRGICDVersionMapping` | ICD编码映射表（地方ICD ↔ 医保ICD） |
| `BS_DRGICDInfo` | 各地方版本ICD编码信息表 |
| `HB_DRGBasicData` | DRG基础数据主表（医保ICD编码来源） |
| `HB_DRGBasicDataSub` | DRG基础数据明细表（医保ICD编码来源） |

## 涉及的接口服务

### ICD编码映射

| 接口码 | 操作 | 说明 |
|--------|------|------|
| 02010022 | 查询 | 查询医保ICD编码信息（右侧选择数据源） |
| 02010023 | 保存 | 保存ICD编码映射关系 |
| 02010023 | 删除 | 删除ICD编码映射关系 |
| 02010023 | 查询 | 查询ICD编码映射关系 |

### ICD编码查询

| 接口码 | 操作 | 说明 |
|--------|------|------|
| 02010037 | 查询 | 查询各地方版本ICD编码信息 |

> **注意**：02010024（删除ICD编码映射关系）和 02010025（查询ICD编码映射关系）在后端源码中未找到实现，相关功能已合并在 02010023 接口码下。
> BS_DRGICDInfo 的增删改接口服务尚未生成。

## 功能范围

### ICD编码映射页面
- 查询条件：地方ICD代码/描述、医保ICD代码/描述、省市、版本号
- 数据表格：展示映射关系列表（分页）
- 新增映射：选择地方ICD编码 + 医保ICD编码，建立映射
- 编辑映射：修改已有映射关系
- 删除映射：单条/批量删除

### ICD编码查询页面
- 查询条件：ICD代码/描述、版本（ICD-9/ICD-10）、省市、状态
- 数据表格：展示ICD编码列表（分页）
- 仅查询功能，暂不支持增删改（后端接口未生成）
