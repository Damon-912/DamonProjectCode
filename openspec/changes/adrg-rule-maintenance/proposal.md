# ADRG分组规则维护

## 概述

在"基础数据管理"模块下新增 **ADRG分组规则维护** 页面，用于管理核心疾病诊断相关分组（ADRG）规则列表。该规则是DRG分组器执行ADRG分组时的核心依据。

## 背景

- ADRG（核心疾病诊断相关分组）是DRG分组的第一阶段产出
- 分组规则定义了各ADRG的入组条件：主要诊断、其他诊断、主要手术/操作、其他手术/操作
- 规则分为联合分组规则（UnionFlag=1）和非联合分组规则（UnionFlag=0）
- 不同地区可维护不同的规则版本（通过省/市区分）

## 涉及的数据库表

| 表名 | 说明 |
|------|------|
| `CB_DRGCoreGroupsList` | ADRG核心疾病诊断相关分组规则列表 |

## 涉及的接口服务

| 接口码 | 操作 | 说明 |
|--------|------|------|
| 02010016 | 保存 | 保存ADRG核心疾病诊断相关分组规则（新增/修改） |
| 02010017 | 查询 | 查询ADRG核心疾病诊断相关分组规则列表（分页） |
| 02010018 | 删除 | 删除ADRG核心疾病诊断相关分组规则 |

## 功能范围

### ADRG分组规则维护页面
- 查询条件：ADRG名称（模糊匹配）、状态（全部/有效/无效）
- 数据表格：展示规则列表（分页），核心字段包括ADRG代码、ADRG名称、主要诊断、主要手术、联合标志、状态、生效/失效日期
- 新增规则：弹窗表单录入完整的规则信息（ADRG代码/名称、三级诊断编码、三级手术编码、联合标志、省市、日期等）
- 编辑规则：修改已有规则
- 删除规则：单条删除
- 规则详情：可展开查看完整的诊断和手术编码信息
