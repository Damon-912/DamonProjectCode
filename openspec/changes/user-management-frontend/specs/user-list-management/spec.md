## ADDED Requirements

### Requirement: 用户分页列表查询
系统SHALL提供用户分页列表页面，支持按医院、用户编码、姓名、状态筛选条件查询用户信息，对接后端接口 code 01030101；后端会根据session中的groupID和hospID自动进行数据权限过滤。

#### Scenario: 默认加载用户列表
- **WHEN** 用户进入用户管理页面
- **THEN** 系统默认按当前登录用户所属医院加载用户列表，分页大小为20，显示用户编码、姓名、性别、所属医院、手机号、证件类型、证件号、状态、创建人、创建时间列

#### Scenario: 按条件筛选用户
- **WHEN** 用户选择医院、输入用户编码或姓名、选择状态后点击查询
- **THEN** 系统调用 FindUserDetail 接口，传递对应筛选参数，刷新列表展示结果

#### Scenario: 分页切换
- **WHEN** 用户切换分页页码或修改每页条数
- **THEN** 系统保持当前筛选条件，重新请求对应页数据

#### Scenario: Session失效处理
- **WHEN** 调用查询接口时后端返回session失效错误
- **THEN** 系统提示"登录已过期，请重新登录"并跳转至登录页面

### Requirement: 新增用户
系统SHALL提供新增用户功能，对接后端接口 code 01030102，创建新用户记录并关联医院；后端使用session.userID作为创建人。

#### Scenario: 打开新增用户弹窗
- **WHEN** 用户点击"新增"按钮
- **THEN** 系统打开新增用户表单弹窗，包含用户姓名(必填)、手机号(必填,11位)、性别(必填)、证件类型、证件号、出生日期、工作手机、邮箱、昵称、头像、简介、所属医院(必填)、启用日期(必填)、停用日期、状态(必填,默认启用)字段

#### Scenario: 提交新增用户
- **WHEN** 用户填写完表单点击确定
- **THEN** 系统调用 AddUserConf 接口（自动携带session信息），成功后关闭弹窗并刷新列表，显示成功提示；失败时显示错误信息（如手机号已注册）

#### Scenario: 手机号校验
- **WHEN** 用户输入手机号不满足11位
- **THEN** 表单校验不通过，提示"请输入正确的手机号"

#### Scenario: 无权限新增用户
- **WHEN** 当前用户session的groupID无用户管理权限时尝试新增
- **THEN** 后端返回权限不足错误，前端提示"您没有权限执行此操作"

### Requirement: 编辑用户
系统SHALL提供编辑用户功能，对接后端接口 code 01030102（复用新增接口，通过userDr字段区分）；后端使用session.userID作为更新人。

#### Scenario: 打开编辑用户弹窗
- **WHEN** 用户点击列表某行的"编辑"按钮
- **THEN** 系统打开编辑用户表单弹窗，回填该用户的当前信息

#### Scenario: 提交编辑用户
- **WHEN** 用户修改表单后点击确定
- **THEN** 系统调用 AddUserConf 接口（携带userDr字段和session信息），成功后关闭弹窗并刷新列表

### Requirement: 用户状态显示
系统SHALL在用户列表中用标签样式显示用户状态（Y=启用/绿色, N=停用/红色）。

#### Scenario: 启用状态显示
- **WHEN** 用户列表中某用户Active字段为"Y"
- **THEN** 状态列显示绿色"启用"标签

#### Scenario: 停用状态显示
- **WHEN** 用户列表中某用户Active字段为"N"
- **THEN** 状态列显示红色"停用"标签
