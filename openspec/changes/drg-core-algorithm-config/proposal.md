# DRG核心算法配置维护

## 概述

在"基础数据管理"模块下新增 **DRG核心算法配置维护** 页面，用于管理DRG核心算法参数（基准点数、预估点值、病组差异系数、支付标准等）。该配置是DRG分组器计算DRG支付标准的核心依据。

## 背景

- DRG核心算法配置定义了各DRG分组在不同地区、不同医疗机构的支付参数
- 核心字段包括：DRG编码、基准点数(Points)、预估点值(PipValue)、病组差异系数(DGDOV)、支付标准(PayStandard)
- 支持按省市、医疗机构区分不同版本的配置
- 通过生效/失效日期控制配置的有效性

## 涉及的数据库表

| 表名 | 说明 |
|------|------|
| `HB_DRGCoreAlgorithmData` | DRG核心算法配置表 |

## 涉及的接口服务

| 接口码 | 操作 | 说明 |
|--------|------|------|
| 02010032 | 保存 | 保存DRG核心算法配置（新增/修改） |
| 02010033 | 查询 | 查询DRG核心算法配置列表（分页） |
| 02010034 | 删除 | 删除DRG核心算法配置 |

## 功能范围

### DRG核心算法配置维护页面
- 查询条件：DRG编码（模糊）、医疗机构名称（模糊）、医疗机构代码、省市、状态（全部/有效/无效）
- 数据表格：展示配置列表（分页），核心字段包括DRG编码/描述、基准点数、预估点值、病组差异系数、支付标准、险种、医疗机构、状态
- 新增配置：弹窗表单录入完整的配置信息
- 编辑配置：修改已有配置
- 删除配置：单条删除
