## ADDED Requirements

### Requirement: 科室盈亏报表展示
系统SHALL提供科室盈亏报表页面，展示各科室的盈亏统计和分析。

#### Scenario: 查看科室盈亏
- **WHEN** 用户选择统计月份
- **THEN** 系统调用02010201接口查询科室盈亏数据
- **AND** 显示科室盈亏排名、盈亏金额、盈亏率

#### Scenario: 查看盈亏趋势图
- **WHEN** 用户查看科室盈亏页面
- **THEN** 系统展示科室盈亏柱状图
- **AND** 用绿色表示结余、红色表示亏损

### Requirement: 医生盈亏分析功能
系统SHALL提供医生盈亏分析页面，支持按医生维度查询盈亏情况。

#### Scenario: 查询医生盈亏
- **WHEN** 用户选择时间范围和科室
- **THEN** 系统调用02010202接口查询医生盈亏数据
- **AND** 显示医生管床数、总盈亏、平均盈亏率
