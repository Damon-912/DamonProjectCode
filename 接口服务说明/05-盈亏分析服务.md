## 5.1 查询科室盈亏 (02010201)

> 接口Code: `02010201`
> 接口名称: 查询科室盈亏
> 方法名: QueryDeptProfit

### 入参

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| year | String | 否 | 年份 | "2026" |
| month | String | 否 | 月份 | "03" |
| deptCode | String | 否 | 科室编码 | "01" |
| startDate | String | 否 | 开始日期 | "2026-03-01" |
| endDate | String | 否 | 结束日期 | "2026-03-31" |
| page | Number | 否 | 页码，默认1 | 1 |
| limit | Number | 否 | 每页条数，默认20 | 20 |

### 出参

| 字段 | 类型 | 说明 |
|------|------|------|
| errorCode | String | 错误码 |
| errorMessage | String | 错误信息 |
| result.total | Number | 总记录数 |
| result.rows | Array | 盈亏列表 |

#### result.rows 每项字段

| 字段 | 类型 | 说明 |
|------|------|------|
| deptCode | String | 科室编码 |
| deptName | String | 科室名称 |
| totalCaseCount | Number | 总病例数 |
| groupedCaseCount | Number | 已分组病例数 |
| groupRate | Number | 分组率(%) |
| totalFee | Number | 总费用 |
| payStandard | Number | DRG支付标准 |
| profitAmount | Number | 盈亏金额 |
| profitRate | Number | 盈亏率(%) |
| cmi | Number | CMI值 |
| avgFee | Number | 次均费用 |
| avgHospitalDays | Number | 平均住院天数 |

### 请求示例

```json
{
  "code": "02010201",
  "params": [{
    "year": "2026",
    "month": "03",
    "startDate": "2026-03-01",
    "endDate": "2026-03-31",
    "page": 1,
    "limit": 20
  }]
}
```

### 响应示例

```json
{
  "errorCode": "0",
  "errorMessage": "",
  "result": {
    "total": 15,
    "rows": [
      {
        "deptCode": "01",
        "deptName": "心内科",
        "totalCaseCount": 320,
        "groupedCaseCount": 298,
        "groupRate": 93.13,
        "totalFee": 5680000.00,
        "payStandard": 5200000.00,
        "profitAmount": -480000.00,
        "profitRate": -8.45,
        "cmi": 1.23,
        "avgFee": 17750.00,
        "avgHospitalDays": 8.5
      }
    ]
  }
}
```
