## 4.1 查询预警规则 (02010101)

> 接口Code: `02010101`
> 接口名称: 查询预警规则
> 方法名: QueryWarningRules

### 入参

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| ruleCode | String | 否 | 规则编码 | "WR001" |
| ruleName | String | 否 | 规则名称 | "费用超支预警" |
| ruleType | String | 否 | 规则类型：01=费用超支, 02=低倍率, 03=高倍率 | "01" |
| isActive | String | 否 | 是否启用：Y/N | "Y" |
| page | Number | 否 | 页码，默认1 | 1 |
| limit | Number | 否 | 每页条数，默认20 | 20 |

### 出参

| 字段 | 类型 | 说明 |
|------|------|------|
| errorCode | String | 错误码 |
| errorMessage | String | 错误信息 |
| result | Array | 预警规则列表 |

#### result 每项字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Number | 规则ID |
| ruleCode | String | 规则编码 |
| ruleName | String | 规则名称 |
| ruleDesc | String | 规则描述 |
| ruleType | String | 规则类型 |
| thresholdType | String | 阈值类型 |
| thresholdValue | String | 阈值 |
| mdcCode | String | MDC编码 |
| adrgCode | String | ADRG编码 |
| drgCode | String | DRG编码 |
| warningLevel | String | 预警级别 |
| isActive | String | 是否启用 |
| seqNo | Number | 排序号 |
| createDate | String | 创建日期 |
| createTime | String | 创建时间 |

### 请求示例

```json
{
  "code": "02010101",
  "params": [{
    "ruleType": "01",
    "isActive": "Y",
    "page": 1,
    "limit": 20
  }]
}
```

### 响应示例

```json
{
  "errorCode": "0",
  "errorMessage": "",
  "result": [
    {
      "id": 1,
      "ruleCode": "WR001",
      "ruleName": "费用超支预警",
      "ruleDesc": "当总费用超过DRG支付标准的设定比例时触发预警",
      "ruleType": "01",
      "thresholdType": "percent",
      "thresholdValue": "120",
      "mdcCode": "",
      "adrgCode": "",
      "drgCode": "",
      "warningLevel": "high",
      "isActive": "Y",
      "seqNo": 1,
      "createDate": "2026-03-01",
      "createTime": "10:30:00"
    }
  ]
}
```

## 4.2 保存预警规则 (02010102)

> 接口Code: `02010102`
> 接口名称: 保存预警规则（新增/修改）
> 方法名: SaveWarningRule

### 入参

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| ruleId | String | 否 | 规则ID（为空则新增） | "1" |
| ruleCode | String | **是** | 规则编码 | "WR001" |
| ruleName | String | **是** | 规则名称 | "费用超支预警" |
| ruleDesc | String | 否 | 规则描述 | "费用超过标准120%" |
| ruleType | String | **是** | 规则类型 | "01" |
| thresholdType | String | 否 | 阈值类型 | "percent" |
| thresholdValue | String | 否 | 阈值 | "120" |
| mdcCode | String | 否 | MDC编码 | "F" |
| adrgCode | String | 否 | ADRG编码 | "FB1" |
| drgCode | String | 否 | DRG编码 | "FB13" |
| warningLevel | String | 否 | 预警级别 | "high" |
| isActive | String | 否 | 是否启用 | "Y" |
| seqNo | String | 否 | 排序号 | "1" |

### 出参

| 字段 | 类型 | 说明 |
|------|------|------|
| errorCode | String | 错误码 |
| errorMessage | String | 错误信息 |
| result.id | Number | 规则ID |

### 请求示例

```json
{
  "code": "02010102",
  "params": [{
    "ruleCode": "WR001",
    "ruleName": "费用超支预警",
    "ruleDesc": "费用超过DRG支付标准120%",
    "ruleType": "01",
    "thresholdType": "percent",
    "thresholdValue": "120",
    "warningLevel": "high",
    "isActive": "Y",
    "seqNo": "1"
  }]
}
```

### 响应示例

```json
{
  "errorCode": "0",
  "errorMessage": "保存成功",
  "result": { "id": 1 }
}
```
