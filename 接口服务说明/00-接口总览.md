## 1. 通用请求/响应结构

### 1.1 通用请求格式

```json
{
  "code": "02010001",
  "params": [
    { "业务参数Key": "业务参数Value" }
  ],
  "session": [
    {
      "userId": "158",
      "locId": 1,
      "groupId": "1",
      "hospId": "8",
      "sessionId": "mEezLwofKB",
      "hospCode": "12344"
    }
  ]
}
```

### 1.2 通用响应格式

```json
{
  "errorCode": "0",
  "errorMessage": "",
  "result": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| errorCode | String | 错误码，"0"表示成功 |
| errorMessage | String | 错误信息 |
| result | Object/Array | 返回业务数据 |

### 1.3 分页请求参数

分页参数统一放在 `params[0]` 中：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | Number | 1 | 页码 |
| limit | Number | 20 | 每页条数 |

### 1.4 分页响应结构

```json
{
  "errorCode": "0",
  "errorMessage": "",
  "result": {
    "total": 100,
    "rows": [{ "id": "1" }, { "id": "2" }]
  }
}
```

## 3. 错误码规范

| 错误码 | 说明 |
|--------|------|
| 0 | 成功 |
| -1 | 业务逻辑失败（具体原因见errorMessage） |
| -99 | 系统异常 |
| 05000001 | 登录校验失败 |
