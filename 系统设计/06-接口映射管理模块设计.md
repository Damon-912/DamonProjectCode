# 接口映射管理模块设计文档

## 1. 功能概述

接口映射管理模块用于管理和配置系统中的外部接口服务，支持接口的注册、测试、调用日志记录等功能。

## 2. 数据表设计

### 2.1 接口映射表（CB_MapInterface）

```objectscript
Class User.CBMapInterface Extends (%Persistent, %XML.Adaptor)
{
    /// 接口编码
    Property Code As %String(MAXLEN = 30) [ Required ];
    
    /// 接口名称
    Property Descripts As %String(MAXLEN = 100) [ Required ];
    
    /// 接口类名
    Property ClassName As %String(MAXLEN = 100) [ Required ];
    
    /// 接口方法名
    Property MethodName As %String(MAXLEN = 50) [ Required ];
    
    /// 接口类型（HTTP/WebService/内部）
    Property InterfaceType As %String(MAXLEN = 20);
    
    /// 请求方式（GET/POST）
    Property RequestMethod As %String(MAXLEN = 10);
    
    /// 接口地址
    Property Url As %String(MAXLEN = 500);
    
    /// 请求参数说明
    Property ParamDesc As %String(MAXLEN = 500);
    
    /// 返回值说明
    Property ReturnDesc As %String(MAXLEN = 500);
    
    /// 超时时间（秒）
    Property TimeOut As %Integer [ InitialExpression = 30 ];
    
    /// 重试次数
    Property RetryCount As %Integer [ InitialExpression = 0 ];
    
    /// 启用状态（Y/N）
    Property ActiveFlag As %String(MAXLEN = 1) [ InitialExpression = 'Y' ];
    
    /// 备注
    Property Remarks As %String(MAXLEN = 200);
    
    /// 创建人
    Property CreateUser As %String(MAXLEN = 30);
    
    /// 创建时间
    Property CreateDate As %Date;
    
    /// 创建时间
    Property CreateTime As %Time;
    
    /// 修改人
    Property UpdateUser As %String(MAXLEN = 30);
    
    /// 修改时间
    Property UpdateDate As %Date;
    
    /// 修改时间
    Property UpdateTime As %Time;
    
    /// Index
    Index idxCode On Code [ Unique ];
}
```

**状态**: ✅ 已部署

### 2.2 接口日志表（CB_MapInterfaceLog）

```objectscript
Class User.CBMapInterfaceLog Extends (%Persistent, %XML.Adaptor)
{
    /// 关联接口ID
    Property InterfaceDr As %String(MAXLEN = 50);
    
    /// 调用日期
    Property CallDate As %Date;
    
    /// 调用时间
    Property CallTime As %Time;
    
    /// 调用人ID
    Property CallUserDr As %String(MAXLEN = 50);
    
    /// 调用类型（手动/自动）
    Property CallType As %String(MAXLEN = 20);
    
    /// 调用参数
    Property CallParams As %String(MAXLEN = 4000);
    
    /// 返回数据
    Property ResponseData As %String(MAXLEN = 4000);
    
    /// 调用状态（SUCCESS/FAIL）
    Property CallStatus As %String(MAXLEN = 20);
    
    /// 响应时间（毫秒）
    Property ResponseTime As %Integer;
    
    /// 错误信息
    Property ErrorMessage As %String(MAXLEN = 500);
    
    /// Index
    Index idxInterface On InterfaceDr;
    
    /// Index
    Index idxCallDate On CallDate;
    
    /// Index
    Index idxCallStatus On CallStatus;
}
```

**状态**: ✅ 已创建

## 6. 接口配置说明

### 6.1 接口类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 内部 | INNER | 系统内部方法调用 |
| HTTP | HTTP | HTTP接口调用 |
| WebService | WS | WebService接口调用 |

### 6.2 调用状态

| 状态 | 说明 |
|------|------|
| SUCCESS | 调用成功 |
| FAIL | 调用失败 |

### 6.3 调用类型

| 类型 | 说明 |
|------|------|
| 手动 | 手动触发调用 |
| 自动 | 系统自动调用 |
| TEST | 测试调用 |
