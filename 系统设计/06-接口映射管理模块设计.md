# 接口映射管理模块设计

## 1. 系统架构

### 1.1 整体架构
```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│   前端Vue   │ ───► │   IRIS API  │ ───► │  IRIS Database│
│  (接口管理)  │      │ (Interface) │      │ (CB_MapInterface)│
└─────────────┘      └─────────────┘      └─────────────┘
                            │
                            ▼
                     ┌─────────────┐
                     │ 接口日志表   │
                     │CB_MapInterfaceLog│
                     └─────────────┘
```

### 1.2 模块划分
- **前端**：Vue 3 + Element Plus
- **后端**：IRIS ObjectScript
- **数据库**：IRIS SQL

## 2. 数据库设计

### 2.1 CB_MapInterface 表
```sql
CREATE TABLE CB_MapInterface (
    ID                 BIGINT          PRIMARY KEY AUTO_INCREMENT,
    Code               VARCHAR(8)      NOT NULL UNIQUE,
    Descripts          VARCHAR(50)    NOT NULL,
    ClassName          VARCHAR(100)   NOT NULL,
    MethodName         VARCHAR(50)    NOT NULL,
    StartDate          DATE,
    StopDate           DATE,
    ServiceType        VARCHAR(1)     NOT NULL,  -- S/A/U/D
    ProductCatDr       VARCHAR(50),
    ProductModuleDr    VARCHAR(50),
    SeqNo              VARCHAR(4),
    ServiceIP          VARCHAR(30),
    SessionFlag        VARCHAR(1)     NOT NULL DEFAULT 'Y',  -- Y/N
    TokenFlag          VARCHAR(1)     NOT NULL DEFAULT 'Y',  -- Y/N
    TokenOverTime      VARCHAR(5),
    RWServiceTypeDr    VARCHAR(50),
    UNIQUE KEY idx_class_method (ClassName, MethodName)
);
```

### 2.2 CB_MapInterfaceLog 表
```sql
CREATE TABLE CB_MapInterfaceLog (
    ID                 BIGINT          PRIMARY KEY AUTO_INCREMENT,
    InterfaceCode      VARCHAR(8)      NOT NULL,
    InterfaceName      VARCHAR(100),
    UserID             VARCHAR(50),
    SessionID          VARCHAR(100),
    RequestParams      TEXT,
    ResponseResult     TEXT,
    ExecuteTime        INT,
    Status             VARCHAR(1)      NOT NULL,  -- S/F
    ErrorMessage       VARCHAR(500),
    CreateDate         DATE            NOT NULL,
    CreateTime         TIME            NOT NULL,
    INDEX idx_interface_code (InterfaceCode),
    INDEX idx_user_id (UserID),
    INDEX idx_create_date (CreateDate)
);
```

## 4. 前端设计

### 4.1 菜单结构
```
系统管理
├── 接口映射管理
│   ├── 接口列表
│   ├── 接口测试
│   └── 接口日志
```

### 4.2 页面设计

#### 4.2.1 接口列表页面
- **布局**：查询条件 + 数据表格 + 分页
- **查询条件**：
  - 接口Code（输入框）
  - 接口描述（输入框）
  - 类名（输入框）
  - 方法名（输入框）
  - 服务类型（下拉框：全部/查询/新增/修改/删除）
  - 产品分类（下拉框）
  - 产品模块（下拉框）
- **数据表格列**：
  - 序号
  - 接口Code
  - 接口描述
  - 类名
  - 方法名
  - 服务类型
  - 生效日期
  - 失效日期
  - 操作（编辑/删除/测试）
- **操作按钮**：新增、导出

#### 4.2.2 接口编辑弹窗
- **表单字段**：
  - 接口Code
  - 接口描述
  - 类名
  - 方法名
  - 生效日期
  - 失效日期
  - 服务类型
  - 产品分类
  - 产品模块
  - 序号
  - 服务器地址
  - 是否验证Session
  - 是否验证Token
  - Token超时时间
  - 读写类型

#### 4.2.3 接口测试页面
- **布局**：接口选择 + 参数输入 + 结果展示
- **接口选择**：下拉框选择已配置的接口
- **参数输入**：JSON编辑器
- **结果展示**：
  - 响应状态
  - 响应结果（JSON）
  - 执行时长

#### 4.2.4 接口日志页面
- **布局**：查询条件 + 日志列表
- **查询条件**：
  - 接口Code
  - 调用用户
  - 时间范围
  - 状态
- **日志列表列**：
  - 调用时间
  - 接口Code
  - 接口描述
  - 用户
  - 执行时长
  - 状态
  - 错误信息

## 5. 接口调用规范

```json
{
    "params": [{
        "业务参数1": "value1",
        "业务参数2": "value2"
    }],
    "code": "02010404",
    "session": [{
        "userID": "158",
        "sessionID": "mEezLwofKB"
```

```json
{

    "errorMessage": "",
    "result": {
        "rows": [],
        "total": 0
```

## 6. 安全设计

### 6.1 权限控制
- 接口映射维护需要管理员角色
- 接口测试需要开发人员角色
- 接口日志查询需要审计角色

### 6.2 验证机制
- Session验证：验证用户登录状态
- Token验证：验证请求合法性
- 超时控制：Token过期时间可配置

### 6.3 日志审计
- 所有接口调用均记录日志
- 记录请求参数和响应结果
- 记录执行时长和错误信息
