# 费用预警模块设计文档

## 1. 功能概述

费用预警模块实时监控病案费用与DRG/DIP付费标准的偏差，当费用超出预警阈值时触发预警通知。

## 2. 数据表设计

### 2.1 预警规则表（BS_DRGWarningRule）

```objectscript
Class User.BSDRGWarningRule Extends (%Persistent, %XML.Adaptor)
{
    /// 规则编码
    Property RuleCode As %String(MAXLEN = 20) [ Required, Unique ];
    
    /// 规则名称
    Property RuleName As %String(MAXLEN = 50) [ Required ];
    
    /// 规则类型（超支预警/结余预警/费用异常）
    Property RuleType As %String(MAXLEN = 20) [ Required ];
    
    /// 适用DRG（空表示全部）
    Property DrgCode As %String(MAXLEN = 10);
    
    /// 适用科室（空表示全部）
    Property DeptCode As %String(MAXLEN = 20);
    
    /// 阈值百分比
    Property ThresholdPercent As %Float [ Required ];
    
    /// 预警级别（1提示/2警告/3严重）
    Property WarningLevel As %Integer [ Required ];
    
    /// 是否启用
    Property IsEnabled As %Boolean [ InitialExpression = 1 ];
    
    /// 备注
    Property Remarks As %String(MAXLEN = 200);
    
    /// 创建人
    Property CreateUser As %String(MAXLEN = 30);
    
    /// 创建时间
    Property CreateDate As %Date;
    
    /// 修改人
    Property UpdateUser As %String(MAXLEN = 30);
    
    /// 修改时间
    Property UpdateDate As %Date;
}
```

### 2.2 预警记录表（BS_DRGWarningRecord）

```objectscript
Class User.BSDRGWarningRecord Extends (%Persistent, %XML.Adaptor)
{
    /// 关联病案ID

    /// 关联规则ID

    /// 规则编码
    Property RuleCode As %String(MAXLEN = 20);
    
    /// 规则名称

    Property WarningLevel As %Integer;

    Property TotalCost As %Float;

    Property DrgPayment As %Float;

    /// 处理时间
    Property ProcessDate As %Date;

}
```

## 6. 预警规则类型

| 规则类型 | 代码 | 说明 |
|----------|------|------|
| 费用超支 | 01 | 医疗费用超过DRG支付标准的设定比例 |
| 低倍率 | 02 | 费用低于DRG支付标准的设定比例 |
| 高倍率 | 03 | 费用高于DRG支付标准的设定比例 |
| 编码异常 | 04 | 诊断/手术编码存在异常 |
| 分解住院 | 05 | 疑似分解住院行为 |

## 7. 预警级别

| 级别 | 名称 | 颜色 | 说明 |
|------|------|------|------|
| 1 | 提示 | 绿色 | 需要关注 |
| 2 | 警告 | 黄色 | 需要处理 |
| 3 | 严重 | 红色 | 紧急处理 |

## 8. 处理状态

| 状态 | 说明 |
|------|------|
| 待处理 | 预警产生后待处理 |
| 已处理 | 已完成处理 |
| 已忽略 | 被忽略的预警 |
