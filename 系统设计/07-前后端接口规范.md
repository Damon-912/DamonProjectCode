# 前后端接口规范文档

## 1. 请求格式规范

### 1.1 标准请求结构

```json
{
    "params": [
        {
            // 业务参数
            "param1": "value1",
            "param2": "value2"
        }
    ],
    "code": "02010019",
    "session": [
        {
            "userID": "158",
            "locID": 1,
            "groupID": "1",
            "hospID": "8",
            "sessionID": "mEezLwofKB",
            "hospCode": "12344",
            "language": "",
            "hostName": "",
            "ipv4": "",
            "ipv6": "",
            "mac": ""
        }
    ]
}
```

### 1.2 请求参数说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| params | Array | 是 | 业务参数数组，通常只有一个对象 |
| params[0] | Object | 是 | 业务参数对象 |
| code | String | 是 | 接口服务Code（如02010019） |
| session | Array | 是 | 会话信息数组 |
| session[0].userID | String | 是 | 当前用户ID |
| session[0].locID | Number | 是 | 登录科室ID |
| session[0].groupID | String | 是 | 安全组ID |
| session[0].hospID | String | 是 | 医院ID |
| session[0].sessionID | String | 是 | 会话ID |
| session[0].hospCode | String | 是 | 医院编码 |

### 1.3 前端请求封装示例

```typescript
// api/request.ts
import axios from 'axios';
import { getSessionInfo } from '@/utils/session';

const request = async (options: RequestOptions) => {
  const { code, params = {}, pagination } = options;
  
  // 构建标准请求体
  const requestBody = {
    params: [{
      ...params,
      userID: getSessionInfo('userID'),
      UpdateUserDr: getSessionInfo('userID')
    }],
    code,
    session: [getSessionInfo()]
  };
  
  // 如果有分页参数，添加到params中
  if (pagination) {
    requestBody.params[0].pageSize = pagination.pageSize;
    requestBody.params[0].currentPage = pagination.currentPage;
  }
  
  const response = await axios.post('/api/drg/service', requestBody);
  return response.data;
};

interface RequestOptions {
  code: string;
  params?: Record<string, any>;
  pagination?: {
    pageSize: number;
    currentPage: number;
  };
}
```

## 2. 响应格式规范

### 2.1 标准响应结构

```json
{
    "errorCode": "0",
    "errorMessage": "",
    "result": {}
}
```

### 2.2 响应参数说明

| 字段 | 类型 | 说明 |
|------|------|------|
| errorCode | String | 错误代码，"0"表示成功 |
| errorMessage | String | 错误信息，成功时为空 |
| result | Object/Array | 返回结果 |

### 2.3 响应结果类型

#### 成功响应（列表查询）

```json
{
    "errorCode": "0",
    "errorMessage": "",
    "result": {
        "total": 100,
        "rows": [
            { "id": "1", "name": "..." },
            { "id": "2", "name": "..." }
        ]
    }
}
```

#### 成功响应（单条数据）

```json
{
    "errorCode": "0",
    "errorMessage": "",
    "result": {
        "id": "1",
        "name": "...",
        "details": { ... }
    }
}
```

#### 成功响应（操作成功）

```json
{
    "errorCode": "0",
    "errorMessage": "保存成功",
    "result": {}
}
```

#### 失败响应

```json
{
    "errorCode": "02010019",
    "errorMessage": "查询失败：参数错误",
    "result": {}
}
```

## 4. 后端接口开发规范

### 4.1 ObjectScript方法签名

```objectscript
ClassMethod InterfaceName(jsonObj) As %Library.DynamicObject
{
    new (jsonObj)
    set resultObj = {"errorCode":"0","errorMessage":"","result":{}}
    
    try {
        // 获取params参数
        set params = jsonObj.params.%Get(0)
        set param1 = params.param1
        set param2 = params.param2
        
        // 获取session信息
        set session = jsonObj.session.%Get(0)
        set userID = session.userID
        set hospID = session.hospID
        
        // 业务逻辑处理
        // ...
        
        set resultObj.result = result
    }
    catch(e) {
        set resultObj.errorCode = "接口Code"
        set resultObj.errorMessage = "错误描述"
    }
    
    quit resultObj
}
```

### 4.2 获取分页参数

```objectscript
// 从params中获取分页参数
set pageSize = 50, currentPage = 1
set params = jsonObj.params.%Get(0)
if params.pageSize '= "" {
    set pageSize = params.pageSize
}
if params.currentPage '= "" {
    set currentPage = params.currentPage
}
```

## 6. 前端统一响应处理

```typescript
// utils/responseHandler.ts
import { message } from 'antd';

export const handleResponse = (response: any) => {
  const { errorCode, errorMessage, result } = response;
  
  if (errorCode === '0') {
    return result;
  } else {
    message.error(errorMessage || '操作失败');
    throw new Error(errorMessage);
  }
};

// 在API中使用
export const queryData = async (params: any) => {
  const response = await request({ code: '02010019', params });
  return handleResponse(response);
};
```
