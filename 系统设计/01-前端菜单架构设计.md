# 前端菜单架构设计文档

## 1. 概述

基于React 18 + Ant Design 5构建DRG/DIP医保控费预警系统前端，与已有的IRIS后端服务对接。

## 4. 菜单权限数据模型

### 4.1 菜单表（BS_DRGSystemMenu）

```objectscript
Class User.BSDRGSystemMenu Extends (%Persistent, %XML.Adaptor)
{
    /// 菜单编码
    Property MenuCode As %String(MAXLEN = 20) [ Required, Unique ];
    
    /// 菜单名称
    Property MenuName As %String(MAXLEN = 50) [ Required ];
    
    /// 父菜单编码
    Property ParentCode As %String(MAXLEN = 20);
    
    /// 菜单路径
    Property MenuPath As %String(MAXLEN = 100);
    
    /// 菜单图标
    Property MenuIcon As %String(MAXLEN = 50);
    
    /// 排序号
    Property SortOrder As %Integer;
    
    /// 状态（启用/禁用）
    Property Status As %String(MAXLEN = 10);
    
    /// 关联接口Code列表（逗号分隔）
    Property InterfaceCodes As %String(MAXLEN = 500);
}
```

### 4.2 前端菜单获取接口（Code: 02010401）

```objectscript
ClassMethod GetUserMenus(jsonObj) As %Library.DynamicObject
{
    new (jsonObj)
    set resultObj = {"errorCode":"0","errorMessage":"","result":[]}
    
    try {
        set session = jsonObj.session.%Get(0)
        set userId = session.userId
        
        // 查询用户角色关联的菜单
        set sql = "SELECT m.MenuCode, m.MenuName, m.ParentCode, m.MenuPath, m.MenuIcon "
                 _"FROM BS_DRGSystemMenu m "
                 _"JOIN BS_DRGRoleMenu rm ON m.MenuCode = rm.MenuCode "
                 _"JOIN BS_DRGUserRole ur ON rm.RoleCode = ur.RoleCode "
                 _"WHERE ur.UserId = ? AND m.Status = '启用' "
                 _"ORDER BY m.SortOrder"
        
        set stmt = ##class(%SQL.Statement).%New()
        do stmt.%Prepare(sql)
        set rs = stmt.%Execute(userId)
        
        set menuArr = []
        while rs.%Next() {
            set menuObj = {}
            set menuObj.menuCode = rs.%Get("MenuCode")
            set menuObj.menuName = rs.%Get("MenuName")
            set menuObj.parentCode = rs.%Get("ParentCode")
            set menuObj.menuPath = rs.%Get("MenuPath")
            set menuObj.menuIcon = rs.%Get("MenuIcon")
            do menuArr.%Push(menuObj)
        }
        
        set resultObj.result = menuArr
    }
    catch(e) {
        set resultObj.errorCode = "02010401"
        set resultObj.errorMessage = "获取菜单失败"
    }
    
    quit resultObj
}
```
