# DRG表结构部署说明

## 部署方式一：通过 Management Portal 导入（推荐）

### 步骤：

1. **打开 IRIS Management Portal**
   ```
   http://111.229.137.113:52773/csp/sys/UtilHome.csp
   ```

2. **登录**
   - Username: `_system`
   - Password: `123456`

3. **进入系统资源管理器**
   - 点击 `System Explorer` → `Classes`

4. **导入表结构类**
   - 选择目标命名空间：`USER`
   - 点击 `Import`
   - 选择以下文件（按住 Ctrl 多选）：
   
   **表结构类：**
   ```
   后端数据库结构开发/DRG后端表结构/BSDRGWarningRule.txt
   后端数据库结构开发/DRG后端表结构/BSDRGWarningRecord.txt
   后端数据库结构开发/DRG后端表结构/BSDRGProfitAnalysis.txt
   后端数据库结构开发/DRG后端表结构/BSDRGDeptSummary.txt
   后端数据库结构开发/DRG后端表结构/BSDRGQCIssue.txt
   后端数据库结构开发/DRG后端表结构/BSDRGSystemUser.txt
   后端数据库结构开发/DRG后端表结构/BSDRGSystemRole.txt
   后端数据库结构开发/DRG后端表结构/BSDRGUserRole.txt
   后端数据库结构开发/DRG后端表结构/BSDRGSystemMenu.txt
   后端数据库结构开发/DRG后端表结构/BSDRGRoleMenu.txt
   后端数据库结构开发/DRG后端表结构/CBHISConnectionConfig.txt  （新增）HIS连接配置表
   ```

5. **导入服务类**
   ```
   src/src/DRG/Warning.cls
   src/src/DRG/Profit.cls
   src/src/DRG/QC.cls
   src/src/DRG/System.cls
   ```

6. **验证部署结果**
   - 进入 `System Explorer` → `SQL`
   - 选择 `USER` 命名空间
   - 执行：`SELECT * FROM SQL_USER.Tables`
   - 确认以下表已创建：
     - `BS_DRGWarningRule`
     - `BS_DRGWarningRecord`
     - `BS_DRGProfitAnalysis`
     - `BS_DRGDeptSummary`
     - `BS_DRGQCIssue`
     - `BS_DRGSystemUser`
     - `BS_DRGSystemRole`
     - `BS_DRGUserRole`
     - `BS_DRGSystemMenu`
     - `BS_DRGRoleMenu`
