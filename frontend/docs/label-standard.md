# 前端标签命名规范

本文档定义了 DRG 医保控费预警系统中所有前端组件的标签（label）命名标准。

## 1. 基本原则

- **全部使用中文**：所有 Form.Item 的 label 必须使用中文
- **简洁明确**：标签文字应简洁明了，一眼能看出字段含义
- **格式统一**：遵循统一的命名格式

## 2. 必填字段标识

### 2.1 必填字段格式

```
* 字段名称
```

示例：
- `* DRG代码`
- `* 诊断名称`
- `* 生效日期`

### 2.2 可选字段格式

```
字段名称
```

示例：
- `备注`
- `排序号`

## 3. 计量单位规范

计量单位统一使用中文括号 `（）` 包裹，放在字段名称末尾。

### 3.1 常用计量单位对照表

| 字段类型 | 标签格式 | 示例 |
|---------|---------|------|
| 年龄 | 字段名称(岁) | 患者年龄(岁)、年龄(岁) |
| 金额 | 字段名称(元) | 总金额(元)、费用(元) |
| 比例/百分比 | 字段名称(%) | 比例(%)、超标比例(%) |
| 天数 | 字段名称(天) | 住院天数(天)、住ICU天数(天) |
| 体重 | 字段名称(kg) | 体重(kg) |
| 身高 | 字段名称(cm) | 身高(cm) |

## 7. 禁止使用的词汇

以下英文词汇禁止直接在 label 中使用：
- `Code`、`Name`、`Desc`、`Type`
- `ID`、`No`、`Num`
- `Add`、`Edit`、`Delete`、`Save`
- `OK`、`Cancel`、`Confirm`

如需使用，请使用对应的中文替代。
