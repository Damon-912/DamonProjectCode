## 2. 入参字段说明

### 2.1 诊断信息 (DiseInfo)

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| MainFlag | Integer | 是 | 主诊断标志：1=主诊断 | 1 |
| DiagSn | Integer | 是 | 诊断序号 | 1, 2, 3... |
| DiagCode | String | 是 | 诊断代码（ICD-10） | "I21.0" |
| DiagName | String | 否 | 诊断名称 | "急性心肌梗死" |

### 2.2 手术信息 (OprnInfo)

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| MainFlag | String | 是 | 主手术标志：1=主手术 | "1" |
| OprnSn | Integer | 是 | 手术序号 | 1, 2, 3... |
| OprnCode | String | 是 | 手术代码（ICD-9-CM-3） | "51.23" |
| OprnName | String | 否 | 手术名称 | "腹腔镜胆囊切除术" |

### 2.3 其他字段

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| MainDiagnosisCode | String | **是** | 主诊断ICD-10编码（与DiseInfo中MainFlag=1对应） | "I21.0" |
| MainOperationCode | String | 否 | 主手术ICD-9-CM-3编码（与OprnInfo中MainFlag=1对应） | "51.23" |
| Sex | String | 否 | 性别：1=男, 2=女 | "1" |
| Age | Integer | 否 | 年龄（岁） | 58 |
| AgeGroupDays | Integer | 否 | 新生儿出生天数（0-28） | 0 |
| NewbornFlag | String | 否 | 新生儿标志：1=是, 0=否 | "0" |
| RespiratorTime | Integer | 否 | 呼吸机时长（小时），≥96h入MDCA | 0 |
| ECMOFlag | String | 否 | ECMO标志：1=是, 0=否 | "0" |
| TransplantFlag | String | 否 | 器官移植标志：1=是, 0=否 | "0" |
| MarrowTransplantFlag | String | 否 | 骨髓移植标志：1=是, 0=否 | "0" |
| HIVFlag | String | 否 | HIV标志：1=是, 0=否 | "0" |
| TraumaLevel | Integer | 否 | 创伤等级（0-5），≥2入MDCZ | 0 |
| Department | String | 否 | 科室 | "心内科" |
| HospitalDays | Integer | 否 | 住院天数 | 10 |
| TotalCost | Number | 否 | 总费用 | 24680.00 |

## 4. 先期分组规则对应

| 病例类型 | 触发参数 | MDC | 示例编码 |
|----------|----------|------|----------|
| 器官移植 | TransplantFlag=1 | MDCA | AC10 |
| 骨髓移植 | MarrowTransplantFlag=1 | MDCA | - |
| ECMO治疗 | ECMOFlag=1 | MDCA | AA13 |
| 呼吸机≥96h | RespiratorTime≥96 | MDCA | AB13 |
| 新生儿 | AgeGroupDays 1-28 | MDCP | PU15 |
| HIV感染 | HIVFlag=1 | MDCY | - |
| 严重创伤 | TraumaLevel≥2 | MDCZ | - |
| 常规病例 | 以上都不满足 | 常规MDC | FB13 |

---

## 5. 错误码说明

| errorCode | 说明 |
|-----------|------|
| 0 | 成功 |
| -1 | 分组失败（具体原因见errorMessage） |
| -99 | 系统异常 |

### 常见错误信息

| errorMessage | 原因 |
|--------------|------|
| 主诊断不能为空 | MainDiagnosisCode为空 |
| 主诊断[xxx]存在CHS-DRG不作为分组规则的疾病诊断列表中 | 主诊断在排除列表中 |
| 进入分组流程前CheckRules校验失败 | 分组前校验未通过 |
