## 校验执行指南

### 自动检查（可脚本化）

1. **需求覆盖**：解析 FR-* 编号，交叉引用模块
2. **API 端点矩阵**：从模块设计提取端点，比较后端规范
3. **实体对齐**：从模块设计解析实体，比较数据库规范
4. **命名一致性**：提取实体/字段名称，检查变体

### 需要人工审查

1. 业务逻辑一致性
2. 用户体验流程完整性
3. 集成点兼容性
4. 安全实现细节

### 执行校验

1. 生成所有规范文档
2. 运行自动检查
3. 审查自动检查结果
4. 对标记项进行人工审查
5. 生成一致性报告
6. 处理严重问题
7. 修复后重新校验
